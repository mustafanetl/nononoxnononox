---
name: Hotel count default
description: Only one hotel by default in TRIP mode; multiple only on explicit request
type: feature
---
TRIP mode plans should include exactly ONE hotel — the single best pick for the user's stated vibe and budget. Only include 2-3 hotel options when the user explicitly asks for choices, alternatives, comparisons, or budget tiers (e.g. "show me cheaper options", "compare hotels", "give me a few options").
